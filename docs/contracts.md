# Engine contracts

These internal boundaries allow the core, agent integration, and gateway to be implemented independently. Go 1.25+, the supported Moby Docker SDK and pure-Go SQLite driver, with native Go engine tests. Existing Python benchmark verifiers and task fixtures remain Python. All artifact strings are English. Never push or create PRs.

## Core (parent-owned)

`LoadCampaign(path string) (Record, error)` validates JSON and returns normalized data with absolute source paths; `ExpandRuns(campaign Record) []Record` produces task/agent/model/harness/trial combinations. A run specification has `task`, `agent`, `model`, `harness`, `trial`, `limits`. Tasks have `id`, `prompt`, `image`, `setup` (lists of argv lists), optional `repository: {source, revision}`, `attachments: [{source, target}]`, `evaluation: {image, tests: [{id, score, command: [str,...]}]}`. Evaluation commands run in a separate container after stopping the agent container. Trusted test files live outside the agent workspace and can be mounted only into the evaluator at `/evaluation`. Agent workspace is mounted at `/workspace`; evaluator mounts a fresh copy, never shares agent processes.

Agent definitions: `{id, kind: "pi"|"opencode", command?: [str,...]}`. Model definitions are OpenRouter model IDs. Harness definitions: `{id, mode: "explicit"|"inherit", files: [{source, target}]}`. Targets are safe relative paths beneath an isolated configuration home; do not copy a whole HOME or ambient environment. Campaign fields: `version: 1`, `tasks`, `agents`, `models`, `harnesses`, `trials`, `concurrency`, `limits: {agent_seconds?, cost_usd?}`. Defaults: one trial, one worker, empty explicit harness. Offline `demo` is a separate CLI command, never an agent kind in live manifests.

`Timeline` consumes normalized lifecycle events; `SummarizeAttempts(attempts)` aggregates gateway attempts without duplicate provider usage. `NewStore(root)` persists JSON-safe results in SQLite and per-run artifacts. `PrepareWorkspace(ctx, task, destination)` stages committed repository snapshots and original attachments, returning `commit`, `warnings`, and hashes. No stage or evaluator may modify the input repository.

## Agent/runtime unit (T3)

Runtime and agent files live in `internal/bench/{adapters,docker,harness}.go` with native Go tests. These Go symbols are internal implementation boundaries, not a new published Go library API.

- `NewDockerRuntime()` manages containers through the supported Docker Engine Go SDK, pinned to an allowed local Unix socket rather than ambient Docker contexts.
- `Runtime.Start(ctx, image, workspace, StartOptions) (string, error)` starts a named container, working directory `/workspace`, isolated HOME `/home/agent`, normal egress, host gateway alias `host.docker.internal`; returns container ID. No Docker socket, host credentials, privileged mode, or whole host HOME mounts.
- `Runtime.Exec(ctx, container, command, timeout) (ExecResult, error)` executes argv in the container.
- `Runtime.Spawn(ctx, container, command, captureStderr) (Process, error)` gives binary stdin/stdout/stderr for Pi RPC or server lifecycle. Pi stderr is drained concurrently and bounded to 64 KiB in surfaced exit diagnostics; stderr readers must not deadlock a process.
- `Runtime.Address(container) (string, error)` returns the container IPv4 bridge address for a host OpenCode client. Do not publish unauthenticated agent APIs on all host interfaces.
- `Runtime.Stop(ctx, container) error` stops all container processes; `Runtime.Remove(ctx, container) error` removes the container. Both tolerate already-stopped/missing containers but surface real daemon errors.
- `StageHarness(files, destination)` copies only explicitly selected file/directory trees to safe relative targets, rejecting traversal, symlink escape and secret-bearing config. `ConfigureHarness(home, kind, model, gatewayURL, token)` configures exclusively the benchmark gateway for Pi/OpenCode and returns explicit container environment settings. Preserve harness instructions/hooks/skills; reject incompatible provider configuration instead of silently wiping it. Token is an ephemeral local gateway capability, not the upstream OpenRouter key. Never include real keys in persisted files.
- `NewPiAdapter(runtime, container, command)` and `NewOpenCodeAdapter(runtime, container, command)` expose `Run(ctx, prompt, model, onEvent, ask) error`. Context cancellation stops protocol work; it does not cancel the subsequent independent evaluator and cleanup.
- Normalized event dictionaries: `{"type":"agent_start","agent_id":"main","parent_id":null}`; `agent_wait`, `agent_resume`, `agent_end` with same ID; `{"type":"message","agent_id":...,"text":...}`; `{"type":"infrastructure_error","message":...}` only with protocol evidence. Use actual child identity when exposed; never fabricate child measurements. Ask invokes `ask(question, metadata)` synchronously for CLI answer, while other event readers must remain alive. Every submitted reply counts once in parent integration. Time only the blocked agent, not the entire run. API/protocol errors raise an actionable exception; never equate prompt acceptance with completion. Document version/capability limits honestly.

## Gateway unit (T4)

The gateway lives in `internal/bench/gateway.go`, with mock-provider tests and `docs/gateway.md`. It shares JSON record helpers but does not depend on orchestration.

- `NewGateway(apiKey, GatewayOptions)` starts a run-scoped listener; the caller owns `Close()`. Options retain the loopback host/ephemeral-port/default OpenRouter upstream and optional cost limit/observer. `BaseURL()` ends in `/v1`, `Token` is a fresh random local capability, `Attempts()` returns independent thread-safe JSON-safe records, and `LimitReached()` / `InfrastructureFailed()` expose race-safe state.
- Host runner passes host `0.0.0.0` only for container reachability; request capability required. No key or prompt logging. Container gateway URL replaces host with `host.docker.internal`. Dashboard remains loopback.
- Proxy `/v1/chat/completions` and model discovery as needed for supported adapters. Do not permit arbitrary URL forwarding, query SSRF, credential forwarding, or upstream redirects. Upstream target is fixed at construction and must be validated. Strip client authorization and send the real key only to the fixed upstream. Request size bounded. No automatic retries.
- Support nonstream JSON and streaming SSE transparently; capture final usage once, do not buffer away stream responsiveness. Record attempts even for errors and disconnects; missing billing is unknown, never zero. Parent/child rollups must not be added again.
- Attempt fields: `attempt_id`, `agent_id` (client `X-AQP-Agent-ID`, default `"unattributed"`), `parent_id` optional, `model`, `status` (HTTP code or null), `error_kind` (`network`, `provider`, `client_disconnect`, `unknown` or null), `input_tokens`, `output_tokens`, `cost_usd` (numbers or null), optional `cached_tokens`, `reasoning_tokens`, `duration_seconds`. Include `usage_complete` bool. Preserve provider request ID when present. Real observed model identity is preferable to requested model where provided.
- Run cost limit rejects new requests once known cumulative billed cost reaches limit, sets `LimitReached()`. In-flight overshoot is possible and must be documented. Missing usage must not be used to claim a hard spend cap. Network errors and provider 5xx/429 may flag `InfrastructureFailed()`; do not classify malformed agent requests as network faults. Events need not block request servicing.

## Verification and boundaries

Workers observe deterministic RED before implementation, then GREEN and refactor; default tests use fake runtime/processes and local mock HTTP servers. Explicitly opt-in local Docker tests use the prepared image and only test-owned containers. No paid requests, remote execution, implicit Docker pulls, repository-wide formatters, or scratch in the worktree. Use Go test temporary directories outside the repository; the parent owns Git and dependency changes. Return commands and exact outcomes, known live-proof gaps, `skill_resolution`, and covered S# IDs. Approximately 400 lines per coherent slice is advisory, not a reason to minify or omit tests. Report scratch paths; the parent owns cleanup.
